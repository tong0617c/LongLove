网页更新后台

适用于已经部署的 longlove-backend。不需要 PowerShell。

1. 复制完整后台代码

此文件已合并字卡引擎与词典，包含已读不回、随机连发、字卡改写、自由抽词、通知定位和限频修复，不含任何密钥。

下载代码文件

2. 替换现有 Worker 入口

打开 Cloudflare → Workers & Pages → longlove-backend → Edit code（编辑代码）。选中当前入口脚本（可能叫 index.js 或 worker.js），全选内容，粘贴刚才复制的完整代码，然后点击 Deploy（部署）。

不要新建 Pages 项目，也不要把整个网站文件夹拖进去。原有 DB 绑定、环境变量和 Secrets 保留。

3. 检查配置

Bindings 中 DB 应绑定 longlove-private。Settings 中保留 BACKEND_TOKEN、BARK_KEY，并确认：

ALLOWED_ORIGIN = https://tong0617c.github.io
SITE_URL = https://tong0617c.github.io/LongLove
BARK_SERVER = https://api.day.app

Triggers 中保留每分钟一次的 Cron。更新代码不会主动恢复已暂停的通知。

4. 验证

刷新 LongLove。若未连后台，先导出本地备份，再连接原后台；已有云端数据时会切换为云端记录。若需要测试主动通知，手动恢复云端通知并开启主动消息。用平时已连接后台的浏览器打开 Bark 通知。

测试 Bark 推送只是测试提示，不会生成聊天消息。真实字卡通知会链接到对应角色和消息；朋友圈、信箱通知会打开对应页面。
