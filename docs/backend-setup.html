让想念，在关掉网页之后也能抵达。

LongLove 的网页可以独立使用。要在网页关闭时生成消息并发送 Bark 通知，需要把项目中的 backend/ 部署到你自己的 Cloudflare。

尚未部署后台时，关闭网页后的主动互动不会运行。Bark 的密钥只设置在 Cloudflare Secret，不填写在前端代码中。

1. 准备 Worker 与数据库

安装 Node.js，在项目的 backend 文件夹打开终端。运行：

npx wrangler login
npx wrangler d1 create longlove-private

把返回的 database_id 填入 backend/wrangler.toml，对应 REPLACE_WITH_YOUR_D1_DATABASE_ID。数据库绑定名称保留 DB。

2. 配置数据表和密钥

npx wrangler d1 execute longlove-private --remote --file schema.sql
npx wrangler secret put BACKEND_TOKEN
npx wrangler secret put BARK_KEY

BACKEND_TOKEN：自己生成至少 24 字符的随机令牌，例如密码管理器生成的 32 位密码。BARK_KEY：Bark App 中的设备密钥，仅 key 部分，不要填整个推送 URL。

自建 Bark 可修改 BARK_SERVER。GitHub Pages：ALLOWED_ORIGIN 为 https://tong0617c.github.io；SITE_URL 为 https://tong0617c.github.io/LongLove。不要在结尾加斜杠。

3. 发布并连接

npx wrangler deploy

在 LongLove「我 → Cloudflare 与 Bark 后台」输入返回的 Worker HTTPS 地址，以及刚设置的 BACKEND_TOKEN。首次连接会先下载本地备份；空数据库会导入当前本地数据，已有数据则读取云端。

点击「测试 Bark 推送」，确认手机收到后再开启主动消息。Cron 每分钟检查一次，实际互动间隔和免打扰时段由网站设置决定。Cloudflare 新 Cron 配置可能需要一段时间传播。

4. 数据与运行限制

连接后，聊天、图片、日历等数据会存入你的私人 D1 数据库。所有读写需访问令牌；请保密，不要将此后台改为公开共享服务。

定时互动先持久化，再推送；失败推送最多重试 5 次。外部推送在网络超时等异常下无法保证绝对只投递一次。免打扰按 UTC+8 计算。后台未设置 Bark 密钥时不会自动生成互动。

定期从网页导出备份。每份应用数据上限 25MB，图片上传时会压缩。Bark、Cloudflare 和网络的实际可用性会影响送达时间。
